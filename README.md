# Hedge

A garden design app for DIY home gardeners. People photograph a rough sketch of their
garden and get back a professional-looking technical plan they can edit.

The app is organised around four areas: Planning, Designing, Building and Maintaining.

## What's here

- `app/` - the Hedge app proof of concept (Expo, iPhone, Android and web). See its README.

- `prototype/sketch-to-plan/` - first prototype: the Claude API reads a sketch photo into a
  structured layout, and a renderer draws it as a technical garden plan. See its README.
